# Portfolio

**Owner:** Repository entrypoint

A software development portfolio with a local frontend foundation.

The application lives in [frontend/](frontend/README.md). Read the [agent rules](AGENTS.md) before changes.

```bash
cd frontend
nvm use
npm ci
npm run dev
```

Node 22.23.2 is pinned in `frontend/.nvmrc`. npm is the only package manager.
The current page is a setup shell. Personal content and final design remain PLANNED.
